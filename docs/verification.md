## Real scheduled execution

실행 중인 Docker 서버에 2026-11-24 14:23 UTC 예약을 등록했습니다. 서버를 재시작하지 않은 상태에서 14:23:04 UTC에 자동 실행이 시작되어 성공했고, `trigger: scheduled`, 해당 `scheduleId`, `scheduledFor: 2026-11-24T14:23:00.000Z`, 마트 12건을 확인했습니다. 다음 실행은 다음 날로 이동했습니다. 검증용 예약은 이후 삭제했고 실행 기록은 유지했습니다.
